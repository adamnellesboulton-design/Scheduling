Constraint-solver (OR-Tools CP-SAT) Contract-compliant by construction Three optimized options Excel export
View the code Run the app

This is a decision-support tool that builds an equitable, compliant master work schedule for the pediatric hemodialysis unit and exports it as a clean, print-ready Excel workbook. It treats each nurse's requested shift counts and every contract rule as hard constraints, then optimizes fairness, preferences and clustering as soft goals — producing three genuinely different but equally-compliant options to choose from.

This page is an overview. The interactive app is a Python/Streamlit program — see Run the app for how to launch it.

What it does

Guaranteed in every option, before any preference is weighed.

Exact shift counts

Each nurse works exactly their requested D10 and D5 counts — never more, never fewer.

Contract-aware

The ≤ 6 Saturdays per 9-week weekend cap (25.06(E)), max-consecutive-days, meal/rest periods and the 6-week posting lead time are all modeled and cited.

Three options

Preference-, Equity- and Cluster-maximizing — same counts and rules, different arrangement. Pick the trade-off you like.

Per-nurse guarantees

Opt-in hard ticks: Mon/Wed/Fri off, work-every-week, Friday-before-Saturday. Soft preferences for off-days, even spread, spaced Saturdays and clustering.

Hand-tune safely

Click-to-edit the grid or swap two shifts; everything re-validates live, and "reoptimize to fit" keeps a tricky change compliant with minimal disruption.

Clean Excel out

A four-sheet workbook (Schedule, Summary, Compliance, Config) that prints black-and-white; colour flags problems only.

How the solver decides

Two layers — knowing them lets you explain any cell in the grid.

  • Layer 1 — the fixed schedule (identical in all three options): exact counts, daily coverage where the roster allows, the Saturday rules, job-share separation, unavailability, and any ticked hard guarantees. This already pins down most of the grid.
  • Layer 2 — the arrangement (the only thing that differs): each option weights up one goal — honour ticked preferences, balance the week for equity, or cluster shifts into longer blocks off.

Full technical specification, weights and contract mapping live in SOLVER.md.

Run the app

The interactive scheduler is a Python/Streamlit app with an OR-Tools solver.

GitHub Pages hosts this overview only. The live app needs a Python server and the OR-Tools (CP-SAT) library, which can't run as a static page in the browser. Run it locally, or deploy it free to a Python host such as Streamlit Community Cloud.

Locally:

git clone https://github.com/adamnellesboulton-design/scheduling.git
cd scheduling
pip install -r requirements.txt
streamlit run app.py

Requires Python 3.11+. Then open the URL Streamlit prints (usually http://localhost:8501).
